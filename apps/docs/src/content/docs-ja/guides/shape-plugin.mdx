このガイドでは、実際の例として **矩形プラグイン**（`usketch-plugin-shape-rect`）を題材に進めます。読み終わる頃には、次の機能を持つシェイププラグインの作り方がわかります：

- SVG キャンバスへのシェイプ描画
- ヒットテストと選択のサポート
- 8 個のハンドル全てからのリサイズ対応
- ライブプレビュー付きの描画ツール
- undo/redo システムとの統合

## 全体像

シェイププラグインは通常、次の 2 つを登録します：

1. `ShapeRegistry` への **ShapeDefinition**
2. `ToolRegistry` への **ToolDefinition**（描画ツール）

どちらも 1 つの `setup()` 関数の中で登録します。

## 手順

### 1. シェイプの関数を定義する

まず、シェイプが必要とする固有のフィールドを拡張したインターフェースとして宣言し、`ShapeDefinition` の必須メソッドを実装します：

```tsx
import type { BoundingBox, Point, ResizeHandle, ShapeData } from "@edv4h/usketch-shared";
import { DEFAULT_STYLE } from "@edv4h/usketch-shared";

/** `rectangle` シェイプの固有データ。ほかのプラグインが型安全に読めるように export する。 */
export interface RectangleShapeData extends ShapeData {
  cornerRadius?: number;
}

function render(shape: ShapeData) {
  const data = shape as RectangleShapeData;
  return (
    <rect
      x={data.x}
      y={data.y}
      width={data.width}
      height={data.height}
      rx={data.cornerRadius ?? 0}
      fill={data.style.fill}
      stroke={data.style.stroke}
      strokeWidth={data.style.strokeWidth}
      opacity={data.style.opacity}
    />
  );
}

function getBounds(data: ShapeData): BoundingBox {
  return { x: data.x, y: data.y, width: data.width, height: data.height };
}

function hitTest(data: ShapeData, point: Point): boolean {
  return (
    point.x >= data.x &&
    point.x <= data.x + data.width &&
    point.y >= data.y &&
    point.y <= data.y + data.height
  );
}

function createDefault(params: { id: string; x: number; y: number }): RectangleShapeData {
  return {
    id: params.id,
    type: "rectangle",
    x: params.x,
    y: params.y,
    width: 100,
    height: 80,
    style: { ...DEFAULT_STYLE },
    cornerRadius: 0,
  };
}
```

**パターン。** `ShapeRegistry` は基本の `ShapeData` 型で動くので、`render` / `resize` / `hitTest` が受け取るのは `ShapeData` です。中で拡張した型にキャストすれば（`const data = shape as RectangleShapeData`）、プラグイン固有のフィールドに型安全にアクセスできます。

### 2. リサイズロジックを実装する

8 個のリサイズハンドルを処理します：

```tsx
function resize(data: ShapeData, handle: ResizeHandle, delta: Point): ShapeData {
  let { x, y, width, height } = data;
  switch (handle) {
    case "se":
      width += delta.x;
      height += delta.y;
      break;
    case "nw":
      x += delta.x;
      y += delta.y;
      width -= delta.x;
      height -= delta.y;
      break;
    // ... 8 方向すべてを処理
  }
  return {
    ...data,
    x, y,
    width: Math.max(1, width),
    height: Math.max(1, height),
  };
}
```

サイズ 0 のシェイプが生じないよう、`width` と `height` は常に最小値でクランプしてください。

### 3. 描画ツールを作る

描画ツールは**3 段階パターン**を使います：

```tsx
import { createAddShapeCommand } from "@edv4h/usketch-store";
import { generateId, type CanvasPointerEvent, type ToolContext } from "@edv4h/usketch-shared";

// 実際のプラグインでは drawState は setup() のクロージャ内に置き、モジュールスコープに置かない。
let drawState: { startX: number; startY: number; shapeId: string } | null = null;

function onPointerDown(toolCtx: ToolContext, event: CanvasPointerEvent) {
  const id = generateId();
  drawState = { startX: event.worldPoint.x, startY: event.worldPoint.y, shapeId: id };

  // ライブプレビュー用の一時シェイプを作成
  const shape = createDefault({ id, x: event.worldPoint.x, y: event.worldPoint.y });
  shape.width = 0;
  shape.height = 0;
  shape.style = { ...toolCtx.store.getStyleSettings() };
  toolCtx.store.addShape(shape);
}

function onPointerMove(toolCtx: ToolContext, event: CanvasPointerEvent) {
  if (!drawState) return;
  const x = Math.min(drawState.startX, event.worldPoint.x);
  const y = Math.min(drawState.startY, event.worldPoint.y);
  const width = Math.abs(event.worldPoint.x - drawState.startX);
  const height = Math.abs(event.worldPoint.y - drawState.startY);
  toolCtx.store.updateShape(drawState.shapeId, { x, y, width, height });
}

function onPointerUp(toolCtx: ToolContext) {
  if (!drawState) return;
  const shape = toolCtx.store.getShape(drawState.shapeId);
  if (shape && shape.width > 2 && shape.height > 2) {
    // 一時シェイプを undo 可能なコマンドで置き換える
    toolCtx.store.deleteShape(drawState.shapeId);
    toolCtx.commands.execute(createAddShapeCommand(toolCtx.store, shape));
  } else {
    // サイズが小さすぎるので破棄
    toolCtx.store.deleteShape(drawState.shapeId);
  }
  drawState = null;
  toolCtx.store.setActiveToolId("select");
}
```

**重要パターン**：ライブプレビューにはストアを直接変更し、ポインタアップ時にそれを undo 可能なコマンドへ置き換える。

### 4. setup() で全部を繋ぐ

```tsx
export const rectPlugin: UsketchPlugin = {
  id: "usketch-plugin-shape-rect",
  name: "Rectangle",

  setup(ctx: PluginContext) {
    ctx.shapes.register("rectangle", {
      render,
      getBounds,
      hitTest,
      resize,
      createDefault,
    });

    ctx.tools.register("rectangle-draw", {
      icon: RectIcon,
      cursor: "crosshair",
      shortcut: "r",
      order: 10,
      onPointerDown,
      onPointerMove,
      onPointerUp,
    });
  },
};
```

## アプリのデータを持たせる

プラグイン固有のフィールド（上の `cornerRadius` など）は、拡張したインターフェースに置きます。シェイプの形の一部ではない**アプリやドメインのデータ**（外部への参照、識別子、機能フラグなど）は、代わりに `meta` フィールドを使います：

```tsx
interface WeboardMeta {
  employeeId?: string;
  companyId?: string;
}

const shape: ShapeData<WeboardMeta> = {
  id: "note_1", type: "rect", x: 0, y: 0, width: 200, height: 150,
  style: DEFAULT_STYLE,
  meta: { employeeId: "emp_123", companyId: "co_456" },
};
shape.meta?.employeeId; // string | undefined として型が付く
```

具体的な meta の型は、使う側で `ShapeData<TMeta>` の `TMeta` に渡します。コアの API は `ShapeData` のままです（型引数は使う側ごとに任意）。

`meta` が合わない特別な場合（段階的な移行や、例外的なトップレベルのフィールド）のために、`ShapeData` は名前が `x-` で始まる任意のプロパティも受け付けます：

```tsx
const shape: ShapeData = {
  ...,
  "x-legacyFlag": true, // 逃げ道 — できれば meta を使う
};
```

決まりの全体は [シェイプシステム → シェイプを拡張する](../../concepts/shape-system/#シェイプを拡張する) を参照してください。

## まとめ

- シェイプとツールは**同じプラグイン**に置く — 1 つの概念として扱う。
- ライブプレビューには**ストアを直接変更**、確定アクションには**コマンド**を使う。
- ユーザーが少しだけドラッグしたケース（width/height が閾値未満）を必ず扱う。
- 描画後は選択ツールに戻す — これが期待される UX。
- プラグイン固有のフィールドは `extends ShapeData` のインターフェースで宣言し、アプリのデータは `meta` に入れる。

## tldraw からの移行

`class MyShapeUtil extends ShapeUtil<TMyShape>` を書いていた人向け。uSketch では `ctx.shapes.register()` に渡すただのオブジェクトで同じことを表現します:

- `component(shape)` → `render(data)`
- `getGeometry(shape)` → `getBounds(data)` + `hitTest(data, point)`
- `onResize(info)` → `resize(data, handle, delta)`
- `getDefaultProps()` + `TLBaseShape` の入れ物 → `createDefault(params)`（戻り値は `extends ShapeData` の独自型）
- `shape.props.foo` → `data.foo`（フラット — `width` / `height` / `x` / `y` はコアフィールド）

API 対応表・Yjs データ移行・落とし穴の詳細は [tldraw からの移行](../migrate-from-tldraw/) を参照。
