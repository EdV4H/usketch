uSketch のボードは、1 つの中に複数のページを持てる。ワークショップの工程ごと、設計の画面ごとにページを分け、同じボードの共有設定・メンバー・コメントのままで行き来できる。

- ページごとに別の `Y.Doc`（ページ doc）を使い、**開いたページだけを読み込む**。ページが増えても、開くときの重さは今のページの分だけ
- map・地形などの設定は**ページごと**に持つ
- 開いているページは URL の `?page=<pageId>` に出る。リンクを送ると、相手も同じページを開く

ページを使わないボードは、今までどおり 1 枚のボードとして動く。既存のボードをページ形式へ移す手順（自前のサーバーを持つ利用先向け）は [マルチページへの移行](../multi-page-migration/) を参照。

## ページパネル

ページの操作は HUD のページパネル（`@edv4h/usketch-plugin-pages`）にまとまっている。

| 操作 | やり方 |
| ---- | ------ |
| 切り替え | 一覧のページを押す。`Alt+PageDown`（次）/ `Alt+PageUp`（前） |
| 追加 | 「＋ ページを追加」。今のページの直後に足す |
| 名前を変える | ✎ ボタンか、今のページをダブルクリック |
| 並べ替え | 上へ / 下へ |
| 複製 | 「複製」。シェイプは新しい id で写る |
| 削除・復元 | 削除は印を付けるだけで、「削除したページ」から戻せる。最後の 1 枚は削除できない |

キーは HUD の「キー設定」で付け替えられる（ID は `usketch-plugin-pages:next` / `usketch-plugin-pages:prev`）。

## シェイプを別のページへ移す・コピーする

シェイプを選んでいると、ページパネルに「選択中の N 個を別のページへ」が出る。移す先のページを選んで「移す」か「コピー」を押す。

- 子シェイプ（frame・group の中身）と、両端が含まれるコネクタも一緒に動く
- 移さなかったものへの参照は外れる。親が無くなったものは最上位に、コネクタの外れた端はその場の点に残る
- 移す先では一番手前に並ぶ（重なり順は保つ）
- 「移す」は id を変えない。「コピー」は新しい id で写す
- 終わったあとの「開く」で、移す先のページへ移れる

同時に誰かが移動元のページを編集していても、移したシェイプが移動元に戻ってくることはない（移動元のページ doc の `movedOut` に印を残し、戻ってきたものをプラグインが消す）。

## ページに対応した機能

| 機能 | ページでの動き |
| ---- | -------------- |
| カーソル・選択などのプレゼンス | 同じページにいる人のものだけが見える |
| Members（HUD） | 別のページにいる人には、そのページ名が出る。押すとそのページを開く |
| Follow me | 別のページにいる人も「（別のページ）」付きで一覧に出る。追っている人がページを移ると、同じページへ移って追い続ける |
| コメント | スレッドに書いたページを記録する。一覧で別のページのコメントにはページ名が出て、押すとそのページを開く |
| 発表 | 最後のスライドの次で次のページの先頭へ、最初のスライドの前で前のページの最後へ移る。発表のバーにページ名が出る |
| エクスポート | HUD の「Export PNG / SVG / JSON（全ページ）」で全ページを書き出す。画像はページを縦に並べてページ名の見出しを付け、JSON はページごとにシェイプを並べる |
| ポータル | 画面に固定したポータルは、そのシェイプのあるページでだけ出る |
| 履歴 | コミットはページごとの中身を持つ。ページ形式へ移る前のコミットも見られる |
| AI・サムネイル | サーバーの AI はページを指定して読み書きする（省略時は先頭のページ）。サムネイルは先頭のページから作る |
| MCP | `page_list` でページを一覧し、各ツールの `pageId` で対象のページを選ぶ |

## 組み込むとき

ホストはページを切り替えるたびに `BoardStore` とアプリを作り直す。プラグインには、今のページとページを切り替える関数を渡す。uSketch 本体の `apps/web/src/app.tsx` が参照実装になる。

```ts
import { createPagesPlugin, getPagesApi } from "@edv4h/usketch-plugin-pages";

createPagesPlugin({
	rootDoc, // ページ一覧があるルート doc
	pageId, // 今開いているページ
	switchPage: (id) => navigateToPage(id), // URL の ?page= を変える
	openPageDoc: (id) => pageDocs.open(id), // 複製と、ページをまたぐ移動・コピーに使う
});

// HUD を通さずに使う
const pages = getPagesApi(app.services);
pages?.create({ open: true });
await pages?.moveShapes(["shape-id"], "page-id", { open: true });
```

ページに対応したプラグインは、どれも省略できる `pages` オプションを持つ。渡さなければ今のページの中だけで動く。

| プラグイン | `pages` オプション |
| ---------- | ------------------ |
| `@edv4h/usketch-plugin-follow-me` | `awareness`（ボード全員の awareness）・`currentPageId`・`switchPage` |
| `@edv4h/usketch-plugin-comments` | `currentPageId`・`legacyPageId`・`pageName`・`switchPage` |
| `@edv4h/usketch-plugin-presentation` | `hasPage(step)`・`goToPage(step)`・`pageLabel()` |
| `@edv4h/usketch-plugin-export` | `list()`・`loadShapes(pageId)` |
| `@edv4h/usketch-plugin-portal` | `pageId`・`legacyPageId`（`pages` ではなくオプション直下） |

コメントのページを保存するには、サーバーの `comments` テーブルに `pageId` 列も要る（[移行ガイドの「気をつけること」](../multi-page-migration/) を参照）。
