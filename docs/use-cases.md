## 1. 基本操作

### UC-01: 矩形を描画する

**アクター**: ユーザー
**前提条件**: ボードが開かれている

```
1. ユーザーがツールバーで矩形ツール（R）を選択
2. キャンバス上でドラッグを開始
3. ドラッグ中、リアルタイムで矩形のプレビューが表示される
4. スナッププラグインがグリッドスナップを計算し、ガイドを表示
5. ドラッグを終了すると矩形が確定
6. Yjsドキュメントにシェイプデータが追加される
7. 他の接続中ユーザーにリアルタイムで反映
```

**関与するプラグイン**:
| プラグイン | 役割 |
|-----------|------|
| `usketch-plugin-shape-rect` | 矩形データの生成・描画 |
| `usketch-plugin-snap` | グリッドスナップ計算・ガイド表示 |
| `usketch-plugin-bg-grid` | 背景グリッド（スナップの視覚的参照） |

**レイヤー動作**:
```
[Base Layer]       → キャンバス背景
[Background Layer] → グリッド表示（bg-grid プラグイン）
[Shape Layer]      → 確定済み矩形の描画（shape-rect プラグイン）
[Guide Layer]      → スナップガイドライン（snap プラグイン）
[UI Layer]         → ドラッグ中の矩形プレビュー（shape-rect のツール）
```

### UC-02: シェイプを選択・移動する

**アクター**: ユーザー

```
1. ユーザーがツールバーで選択ツール（V）を選択（またはデフォルト）
2. キャンバス上のシェイプをクリック
3. 選択ハンドル（8方向リサイズグリップ）が表示される
4. シェイプをドラッグして移動
5. スナッププラグインが他のシェイプとのアライメントを計算
6. スマートガイド（距離表示付き）がリアルタイムで表示される
7. ドロップで移動確定
8. Undo履歴に移動コマンドが追加される
```

**関与するプラグイン**:
| プラグイン | 役割 |
|-----------|------|
| `usketch-plugin-tool-select` | 選択状態マシン、ハンドル表示、移動処理 |
| `usketch-plugin-snap` | シェイプ間アライメント、スマートガイド |

---

### UC-03: 複数シェイプを選択・整列する

**アクター**: ユーザー

```
1. 選択ツールで空白エリアからドラッグ開始
2. ドラッグ選択ボックスが表示される
3. ボックスに含まれるシェイプが選択状態になる
4. （または Shift+クリック で個別に複数選択）
5. ツールバーまたは右クリックメニューから「上揃え」を選択
6. 選択中のシェイプが上端に整列される
7. Undo で整列前の状態に戻せる
```

---

### UC-04: フリーハンドで描画する

**アクター**: ユーザー

```
1. ユーザーがツールバーでフリーハンドツール（P）を選択
2. キャンバス上でドラッグ開始
3. ポインタの軌跡がリアルタイムで描画される
4. ドラッグ終了でパスが確定
5. パスの平滑化処理が適用される
6. フリーハンドシェイプとして保存
```

**関与するプラグイン**:
| プラグイン | 役割 |
|-----------|------|
| `usketch-plugin-shape-freedraw` | パスデータの生成・描画・平滑化 |

---

### UC-05: テキストを追加・編集する

**アクター**: ユーザー

```
1. ユーザーがツールバーでテキストツール（T）を選択
2. キャンバス上をクリック
3. テキスト入力用のインラインエディタが表示される
4. テキストを入力
5. エディタ外をクリックして確定
6. 確定後は通常のシェイプとして選択・移動・リサイズ可能
7. ダブルクリックで再度テキスト編集モードに入る
```

**関与するプラグイン**:
| プラグイン | 役割 |
|-----------|------|
| `usketch-plugin-shape-text` | テキストデータ管理、インラインエディタ、フォント描画 |

---

### UC-06: Undo/Redoを使用する

**アクター**: ユーザー

```
1. ユーザーが何らかの操作（シェイプ追加、移動、削除、スタイル変更）を実行
2. 操作がコマンドとしてヒストリスタックに記録される
3. Ctrl+Z で直前の操作を取り消し
4. Ctrl+Shift+Z（または Ctrl+Y）でやり直し
5. コラボレーション中は自分の操作のみがUndo対象
   （他ユーザーの操作はYjs CRDTで管理され、Undo対象外）
```

## 2. スタイリング

### UC-07: シェイプのスタイルを変更する

**アクター**: ユーザー

```
1. シェイプを選択
2. 右パネル（プロパティパネル）にシェイプ固有の設定UIが表示される
   - 共通: 塗りつぶし色、線色、線幅、透明度
   - 矩形: 角丸
   - テキスト: フォント、サイズ、行間
3. 値を変更するとリアルタイムでプレビュー反映
4. 変更はコマンドとして記録（Undo可能）
```

**プラグインの連携**:
- 共通スタイルUIは `core` が提供
- シェイプ固有UIは各シェイププラグインの `propertyPanel` が提供

---

### UC-08: 背景を切り替える

**アクター**: ユーザー

```
1. ツールバーまたは設定メニューから背景設定を開く
2. 登録された背景プラグインの一覧が表示される
   - グリッド（usketch-plugin-bg-grid）
   - ドット（usketch-plugin-bg-dots）
   - なし
3. 背景を選択
4. グリッドサイズ、色、透明度等の設定が可能
5. 設定はボードメタデータとしてYjsドキュメントに保存
```

## 3. コラボレーション

### UC-09: ボードを共有してリアルタイム共同編集する

**アクター**: ユーザーA（オーナー）、ユーザーB（招待者）

```
1. ユーザーAが新しいボードを作成
2. 共有ボタンをクリックし、共有リンクを生成
3. リンクをユーザーBに送信
4. ユーザーBがリンクを開くとボードに参加
5. 両者のカーソル位置がリアルタイムで共有される
   - カーソルにユーザー名とカラーが表示
6. ユーザーAが矩形を追加 → ユーザーBの画面に即座に反映
7. ユーザーBがその矩形を移動 → ユーザーAの画面に即座に反映
8. 同じシェイプを同時に編集した場合、Yjs CRDTが自動マージ
```

**データフロー**:
```
ユーザーA → Yjs Doc (local) → WebSocket → Durable Object → WebSocket → Yjs Doc (local) → ユーザーB
```

---

### UC-10: オフラインで編集し、復帰時に同期する

**アクター**: ユーザー

```
1. ボードを開いて編集中にネットワーク接続が切れる
2. ユーザーはオフラインのまま編集を続行可能
   - ローカルのYjsドキュメント + IndexedDBに保存
   - UIに「オフライン」インジケータが表示される
3. ネットワーク接続が復帰
4. ローカルの変更がサーバーに自動同期
5. 他ユーザーの変更もローカルに反映
6. CRDTにより競合は自動解決
```

## 4. 保存・エクスポート

### UC-11: ボードを自動保存する

**アクター**: システム

```
1. ユーザーが操作を行うたびにYjsドキュメントが更新
2. Yjsの変更がIndexedDBにローカル永続化（即時）
3. オンライン時はWebSocket経由でサーバーにも同期
4. サーバー側のDurable Objectがスナップショットを定期保存
5. ユーザーがブラウザを閉じて再度開いた場合:
   a. まずIndexedDBからローカルデータを復元
   b. サーバーとの差分を同期
```

---

### UC-12: ボードをPNG/SVGでエクスポートする

**アクター**: ユーザー

```
1. メニューから「エクスポート」を選択
2. エクスポート形式を選択（PNG / SVG / PDF）
3. オプション設定:
   - 範囲: 全体 / 選択範囲 / カスタム領域
   - 背景: 含める / 透過
   - 倍率: 1x / 2x / 3x（PNGのみ）
4. 「エクスポート」ボタンをクリック
5. ファイルがダウンロードされる
```

**関与するプラグイン**:
| プラグイン | 役割 |
|-----------|------|
| `usketch-plugin-export` | エクスポートUI、SVG/PNG/PDF変換 |

## 5. 管理

### UC-13: ボード一覧を管理する

**アクター**: ログインユーザー

```
1. ダッシュボードにアクセス
2. 自分が作成した/共有されたボードの一覧が表示される
   - サムネイル
   - タイトル
   - 最終更新日
   - 共有状態
3. ボードをクリックして開く
4. ボードを右クリックで:
   - 名前変更
   - 複製
   - 削除
   - 共有設定
```

---

### UC-14: アカウント不要でボードを作成する（ゲスト）

**アクター**: 未ログインユーザー

```
1. トップページにアクセス
2. 「今すぐ始める」ボタンをクリック
3. アカウント作成なしで新しいボードが開く
4. ローカルストレージ + IndexedDB にデータ保存
5. 共有やクラウド保存を使いたい場合はアカウント作成を促す
6. アカウント作成後、ローカルのボードがクラウドに移行
```

## 6. プラグイン拡張（将来）

### UC-15: サードパーティプラグインを追加する

**アクター**: 開発者 / パワーユーザー

```
1. プラグインマーケットプレイス（将来構想）またはnpmからプラグインを取得
2. アプリの設定で追加プラグインを指定
3. プラグインが動的にロードされ、機能が追加される
   例: usketch-plugin-shape-diamond → ひし形ツールが追加
4. プラグインはツールバー、プロパティパネル、レイヤーに自動統合
```

---

### UC-16: カスタムシェイププラグインを開発する

**アクター**: 開発者

```
1. @usketch/core の型定義をインストール
2. ShapePlugin インターフェースに従ってプラグインを実装:
   - データスキーマ（Zod）
   - レンダラー（React コンポーネント）
   - ヒットテスト・バウンディングボックス計算
   - （オプション）描画ツールの状態マシン（XState）
   - （オプション）プロパティパネル
3. ローカルで動作確認
4. npm publish でプラグインを公開
```
