# uSketch v2 — デザイン外注向け機能要件

Web アプリのデザインを外注するにあたり、現時点で実装済みの機能を**機能要件**として整理したドキュメント。

- 対象: `apps/web`（React 19 + TypeScript / ブラウザ向けシングルページアプリ）
- ベース技術: Yjs によるリアルタイム同期、Better Auth による認証、プラグイン合成型アーキテクチャ
- レスポンシブ対応: デスクトップ前提（モバイル最適化は現状なし）

---

## 1. 画面／ページ一覧

| ルート | 画面名 | 概要 |
|---|---|---|
| `/login` | ログイン | メールベースのサインイン（Better Auth）。OAuth は未対応。 |
| `/device` | デバイス認可 | ユーザーコードを入力して別デバイスを承認するフロー。 |
| `/dashboard` | ダッシュボード | ローカルボード一覧（localStorage）とクラウドボード一覧（API）を並べて表示。作成・削除・リネーム。 |
| `/boards/:boardId` | クラウドボード編集 | リアルタイムコラボ対応のメインホワイトボード。 |
| `/local/:boardId` | ローカルボード編集 | localStorage 同期のスタンドアロン版（オフライン動作）。 |
| `/community` | コミュニティマップ | グリッド状に並んだコミュニティ領域の地図画面。 |
| `/community/:slug` | コミュニティボード | 公開共有スペース（空間チャット・投票・ポータルなど）。 |
| `/benchmark` | ベンチマーク | 開発者用パフォーマンス計測ページ。 |

## 2. ボード編集機能（キャンバス）

### 2-1. 基本操作
- シェイプの**作成・選択・移動・リサイズ・回転・削除**
- **複数選択**（矩形選択、Shift+クリック）
- **コピー／ペースト／複製**（Cmd+C/V/D）
- **Undo / Redo**（Cmd+Z / Cmd+Shift+Z）
- **グループ化／アングループ**
- **Z オーダー操作**（最前面へ／1段前へ／1段後ろへ／最背面へ）

### 2-2. ツール
- **選択ツール**（デフォルト）
- **パンツール**（スペース長押しで一時切替）
- **各シェイプの描画ツール**（下記シェイプ群ごとに対応）

### 2-3. シェイプ種別（実装済み）

**基本図形**
矩形／角丸矩形／楕円／三角形／ひし形／星型／矢印／直線

**コンテンツ系**
テキスト／付箋／画像（ドラッグ&ドロップ投入）／フリーハンド（手書き）

**構造系**
フレーム（プレゼンのスライドにも使用）／グループ／コネクター（経路自動調整）／カウンター（連番）

**UI ワイヤーフレーム（21 種）**
ボタン／入力フィールド／セレクトボックス／チェックボックス／ナビバー／タブ／ブレッドクラム／サイドバー／カード／アバター／バッジ／画像プレースホルダー／テーブル／リスト／モーダル／アラート／トースト／プログレスバー／コンテナー／アコーディオン など

**コミュニティ専用**
ボードポータル（他ボードへのリンク埋め込み）／島型オブジェクト／コミュニティ領域タイル

### 2-4. ビューポート
- ズーム（フィット／イン／アウト／100% リセット）
- パン（ドラッグ／マウスホイール）
- **背景切り替え**（グリッド／ドット／なし）

### 2-5. スナップ・整列
- スマートガイド（他シェイプとのエッジ／センター整列線表示）
- 間隔スナップ（等間隔配置ガイド）

## 3. ボード管理機能

- ボードの**作成・削除・リネーム**
- **ローカルボード**（localStorage）と**クラウドボード**（API）を並列に扱う
- **公開 / 非公開切替**（`isPublic` フラグ）
- **メンバー管理**（メール招待、メンバー一覧表示、権限の削除）
- **共有リンクコピー**

---

## 4. コラボレーション機能（クラウドボードのみ）

- **リアルタイム同期**（Yjs + WebSocket）
- **リモートカーソル表示**（ユーザーごとに色・名前バッジ・ステータス：オンライン／離席／ビジー／プレゼン中）
- **ゴーストアバター**（他メンバーが前回見ていた場所に常駐表示）
- **フォローモード**（他メンバーのビューポートに追従、バナー表示）
- **レーザーポインタ**（ユーザーカラーのストローク、約 2.5 秒で消失）
- **スポットライト**（半径 150px の円形フォーカス、周囲を暗転）
- **ウィッスル**（注目喚起の視覚＋音声エフェクト）
- **リップルエフェクト**（編集箇所に波紋）
- **リアクション**（絵文字バブル、拍手演出）
- **空間チャット**（キャンバス上のバブル型インラインチャット）
- **コミュニティチャット**（コミュニティボード専用）
- **投票ウィジェット**（空間上に配置する投票）
- **アクティビティフィード**（誰が何を編集したかのタイムライン）
- **コメント機能**（シェイプにアンカーしたスレッド、バッジ表示）

---

## 5. AI 機能（クラウドボードのみ）

- **AI チャット**（Cmd+K コマンドパレット、サイドパネルタブ、自然言語からキャンバス操作）
- **AI コパイロット**（作成後の自動提案をゴーストシェイプで表示、受け入れ／却下）
- **AI スマートアクション**（選択シェイプに対するコンテキストメニュー：整理／ラベル付け／翻訳／カスタム）
- **AI 音声入力**
- **AI 画像生成**（プロンプトから画像生成しキャンバス配置）
- **AI 手書き認識**（フリーハンド描画を整形された図形に変換）

---

## 6. プレゼンテーション機能

- **3 モード制御**：`off`（通常）／`edit`（プレゼン編集）／`present`（発表中）
- **スライド = フレームシェイプ**（z-index 昇順でスライド順）
- **スライドナビゲーター**（左サイドパネル、サムネイル・並び替え・追加）
- **発表モードオーバーレイ**
  - 画面下部中央：現在ページ／総ページ数、前／次ボタン
  - 画面上部：プログレスバー
  - 右上：編集モードへ戻る ✕ ボタン
  - 3 秒無操作で UI フェードアウト
- **キーボード操作**：矢印（前／次）／Space・PageDown（次）／PageUp（前）／Home（最初）／End（最後）／Esc（編集へ）
- URL クエリ `?present=1&mode=edit|present` で状態管理（ルート遷移せずに切替）

## 10. 画面構成の優先順位（デザインの重点）

外注デザインで特に意匠が求められる画面／コンポーネントは以下：

1. **ダッシュボード**（/dashboard）— ボード一覧の見せ方、作成 CTA
2. **ボード編集画面**（/boards/:id）— ツールバー、サイドパネル、ステータスバー、キャンバス余白
3. **プレゼンテーション発表モード** — オーバーレイ、プログレスバー、アニメーション
4. **コミュニティマップ**（/community）— グリッド状の地図 UI
5. **共有ダイアログ／メンバー管理モーダル**
6. **AI チャット／コマンドパレット**
7. **ログイン・デバイス認可** — 初回タッチポイント

---

## 11. デザイン上の制約・前提

- デスクトップ Web 前提。モバイル／タブレット最適化は将来課題。
- キャンバスは常に全画面、UI はフローティングレイヤー（現状は半透明 + 角丸が基調）。
- ダーク／ライトのテーマ切替は未実装（現状は暗色ベースのフローティング UI）。
- i18n は日本語 UI 中心（英語対応は未確認）。
- アイコンライブラリは特定のものに固定していない（デザイン側で提案可能）。

---

## 12. 現時点で未実装／スコープ外の機能

デザインしなくてよい領域：

- プラグインマーケットプレイス／ショップ
- メディアライブラリ・テンプレートギャラリー
- アナリティクス／インサイトダッシュボード
- 細粒度の権限管理（エディタ／ビューアロール分離）
- モバイル UI
- ダーク／ライトテーマ切替
- 詳細なオフラインモード（ローカルボードのみ対応）
