## v2の方向性

- **MVP First**: 保存・共有・コラボレーションを最初から組み込む
- **Edge-First**: Cloudflare Workers + Durable Objects で低コスト運用
- **Offline-First**: Yjs（CRDT）によるローカル動作 + オンライン同期
- **パッケージ簡素化**: v1の18パッケージ → 8パッケージに統合
